# Voz e tom

## Idioma

A interface é em **português do Brasil**. Termos consagrados de DJ ficam em inglês: BPM, Deck, Key lock, Crossfader, Cue, Pads, Master, Booth, Sync.

Rótulos técnicos que o código usa como valor também ficam em inglês: `PERFECT`, `HARMONIC`, `CLASH`, `Start`.

## Estilo

| Regra | Exemplo |
|---|---|
| Rótulos de botão com verbo no infinitivo ou substantivo curto | `Sincronizar BPM A → B`, `Limpar`, `Próximo` |
| Ações que abrem diálogo terminam com reticências | `Adicionar pasta…`, `YouTube…` |
| Rótulos de campo terminam com ` :` (espaço + dois-pontos) | `Deck A :`, `BPM :`, `Client ID :` |
| Status e progresso em minúsculas, com reticências | `detectando…`, `carregando…` |
| Tooltips em minúsculas, sem ponto final | `carregar no Deck A`, `duplo clique para resetar` |
| Estados em uma palavra | `Tocando`, `Parado` |
| Estado vazio explica o próximo passo | `Escolha uma pasta do computador ou do pen drive` |
| Títulos de janela: `Nome – Contexto` (meia-risca) | `Set list – Meu Computador`, `songdj – harmonic mixer` |

## Símbolos

| Símbolo | Uso |
|---|---|
| `→` | Direção de uma ação (`A → B`) |
| `⇔` | Comparação entre os decks |
| `·` | Separador de metadados (`8B · 128.0`) |
| `↕` | Troca de anel na roda Camelot |
| `⇧` | Tecla Shift |
| `—` | Separa artista e título (`Artista — Faixa`) |

## Números

- BPM com uma casa decimal: `128.0`. O ponto decimal segue o padrão dos softwares de DJ.
- Tempo no formato `mm:ss` (`01:23`). Na tela do Spotify, `m:ss`.
- Valores com sinal mostram o `+` explícito: `+3`, `-2`, `0`.
